# 网页小宠物功能规划

## 目标

小宠物不是装饰品，而是个人站的轻量陪伴交互：它要服务“知识库沉淀、项目展示、个人风采、有趣菜单”这四个方向。默认不打扰阅读，在合适时机给出微反馈，让页面显得更有生命力。

## 审美原则

- 体量小：默认停留在左下角 Dock 附近或页面边缘，不遮挡正文、导航、卡片标题。
- 质感克制：优先使用 CSS/SVG 小动画，减少廉价弹窗感；颜色跟随当前主题。
- 互动少而准：阅读、搜索、切主题、随机打开内容时给反馈，避免持续讲话。
- 可隐藏：提供“安静模式”，写入 localStorage，访客可以一键收起。

## MVP 功能

1. 基础状态
   - idle：默认待机，轻微呼吸或眨眼。
   - reading：进入文档详情页后，安静地显示阅读进度提示。
   - discover：随机打开内容、搜索命中内容时，给一次短反馈。
   - sleep：用户长时间无操作或开启安静模式后休眠。

2. 页面感知
   - 文档详情页：根据滚动进度提示“已读 25% / 50% / 75%”。
   - 项目详情页：在关键指标区域出现一次项目亮点提示。
   - 搜索面板：搜索无结果时给出“换个关键词”的轻提示。
   - 趣味实验室：切换为更活跃的状态，可作为小游戏入口提示。

3. 用户控制
   - 左下角 Dock 增加一个宠物入口。
   - 支持显示 / 隐藏 / 安静模式。
   - 状态保存到 localStorage。

## 交互设计

- 点击宠物：展开一个小菜单，包含“安静模式”“随机推荐”“回到顶部”。
- 拖动宠物：可拖到左右边缘吸附，刷新后记住位置。
- 长按宠物：进入安静模式。
- 阅读完成：显示一次简短祝贺，然后自动收起。

## 技术方案

- 第一阶段：继续使用 `src/features/pet/petEngine.ts`，以 DOM + CSS 动画实现。
- 状态层：新增 `petState.ts`，负责 mood、visible、quiet、position。
- 事件层：监听 route change、scroll progress、search result、theme change。
- 视觉层：先用 CSS 绘制简单形象，后续可接入 Rive 或 Lottie 动画。
- 数据层：localStorage 保存用户偏好，不引入后端。

## 第三方工具候选

- Rive：适合后续做高质量状态机动画，但需要设计文件配合。
- Lottie：适合导入现成小动画，成本低，但风格一致性要把控。
- Motion One / GSAP：当前项目已有 GSAP，第一阶段继续沿用即可。

## 迭代路线

1. V0.1：左下角出现可隐藏宠物，支持 idle / sleep。
2. V0.2：接入文档阅读进度和搜索反馈。
3. V0.3：加入拖动吸附、安静模式、随机推荐。
4. V0.4：替换为更精致的 Rive/Lottie 动画资产。
5. V1.0：形成个人站专属陪伴入口，串联知识库、项目、趣味实验室。
