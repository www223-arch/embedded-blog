# 电机速度环频域分析 SOP

## 问题边界

频域分析不是替代时域波形，而是帮助判断周期性速度波动来自机械结构、电角度误差、采样混叠还是控制器带宽设置。

## 记录项

- 固件版本、PWM 与控制环频率
- 母线电压、目标速度和负载
- 原始角度、估算速度、目标速度与电流指令
- 采样长度、窗函数和频率分辨率

## 流程

1. 保留原始时序数据，不先做平滑。
2. 去除直流分量并记录所用窗函数。
3. 对比机械转频、电频率、编码器每转误差和控制周期相关频率。
4. 每次只改变一个变量，并保留前后频谱。
5. 对可疑峰值回到时域验证，避免只凭频谱下结论。
