# 步进电机闭环实验起步记录

## 目标

先得到一条可重复执行的电机实验链路。这个阶段不评价控制性能，只确认供电、相序、编码器方向、控制周期与日志记录方式能够被复查。

## 最小检查单

1. 断电确认电机相线和编码器接线。
2. 限制母线电流与目标速度，从低能量状态开始。
3. 分别验证开环旋转方向、编码器增量方向和机械零位。
4. 记录固件版本、参数、供电和负载条件。
5. 连续执行三次相同步骤，结果一致后才进入调参。

## 当前结论

实验链路已经跑通，后续报告将在同一基线上补充波形、参数快照与异常复现条件。
