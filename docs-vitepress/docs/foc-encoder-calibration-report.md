# 编码器校准与低速速度波动实验报告

## 当前问题

低速运行时仍能观察到周期性速度波动。当前需要把编码器零位偏置、每转周期误差、采样周期和速度估算方法的影响分开，而不是继续同时修改多个控制参数。

## 工作假设

1. 编码器机械或电气周期误差会在固定转频附近形成稳定峰值。
2. 零位偏置会通过电角度误差影响转矩脉动。
3. 速度差分与滤波参数会放大或隐藏真实波动。

## 下一轮实验矩阵

| 变量 | 保持项 | 观察量 |
| --- | --- | --- |
| 零位偏置 | 速度与负载 | `Iq`、速度纹波、频谱峰值 |
| 速度估算窗口 | 零位与控制参数 | 相位滞后、峰峰值 |
| 采样周期 | 机械状态 | 混叠与噪声底 |

## 当前状态

页面先沉淀实验结构。实测曲线、校准前后对照和结论将在下一轮数据整理后追加，不提前宣称问题已经解决。
